=====================================================
  LINKGEEK - INSTALLATION
=====================================================
(English below)

Linkgeek n'est pas encore signé numériquement (projet indépendant),
donc Windows peut se méfier. C'est normal, voici comment faire.


METHODE 1 - L'installateur .exe
-------------------------------
Lance Linkgeek-Setup-x.x.x.exe.

Si Windows affiche "Windows a protégé votre ordinateur" :
  -> clique sur "Informations complémentaires"
  -> puis sur "Exécuter quand même".


METHODE 2 - Le .zip (si Windows BLOQUE complètement le .exe)
-----------------------------------------------------------
Message "Le Contrôle intelligent des applications a bloqué..."
sans bouton pour continuer ? Utilise le .zip :

  1. Clic droit sur Linkgeek-Setup-x.x.x.zip -> Propriétés.
     En bas, coche "Débloquer" (si la case existe) -> OK.
  2. Clic droit sur le .zip -> "Extraire tout..." -> Extraire.
  3. Ouvre le dossier extrait (PAS le dossier "app" à l'intérieur)
     et double-clique sur "Installer Linkgeek".
  4. Une fenêtre noire s'ouvre : réponds O (oui) ou N (non) puis Entrée
     aux 2 questions (raccourci sur le Bureau, lancement avec Windows).
  5. Attends "Installation terminée !" : Linkgeek s'ouvre tout seul.
     Il est ensuite dans le menu Démarrer.

Ne lance pas le fichier .exe ni le "Linkgeek.exe" du dossier "app".


ENSUITE
-------
- Linkgeek se met à jour tout seul, plus besoin de réinstaller.
- Connexion : Paramètres -> Compte -> "Continuer avec Google".
- Un problème ? Rejoins le Discord LinkGeek, salon #aide.


=====================================================
  ENGLISH - HOW TO INSTALL
=====================================================

Linkgeek is not digitally signed yet (independent project),
so Windows may be cautious. This is normal.

METHOD 1 - The .exe installer
  Run Linkgeek-Setup-x.x.x.exe.
  If Windows says "Windows protected your PC":
  click "More info", then "Run anyway".

METHOD 2 - The .zip (if Windows BLOCKS the .exe completely,
"Smart App Control blocked..." with no way to continue)
  1. Right-click Linkgeek-Setup-x.x.x.zip -> Properties.
     At the bottom, tick "Unblock" (if it is there) -> OK.
  2. Right-click the .zip -> "Extract All..." -> Extract.
  3. Open the extracted folder (NOT the "app" folder inside it)
     and double-click "Installer Linkgeek".
  4. A black window opens: answer O (yes) or N (no) then Enter
     to the 2 questions (desktop shortcut, start with Windows).
  5. Wait for "Installation terminee !": Linkgeek opens by itself.

AFTER THAT
- Linkgeek updates itself, no need to reinstall.
- Sign in: Settings -> Account -> "Continue with Google".
- A problem? Join the LinkGeek Discord, #english-help channel.
